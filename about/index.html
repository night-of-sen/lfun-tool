About

156 curated open-source projects, with clear notes on how to use them

The problem we solve

GitHub is full of excellent projects, but most READMEs are long, English, and written for developers. After reading one you often still don't know: can I use this right now? What do I install? Where does it run? This site answers that up front — every entry is tagged with how to use it and on which platforms.

What gets listed

Open-source projects only, and they must do something real (not a tutorial, not just docs), still be maintained or have a clear purpose, and have a clear license. Entries that get archived or go dormant are flagged as "Archived".

How the usage tags work

Online = there's an official hosted version you can open right away. Self-hosted = a web app you deploy yourself, usually with Docker. Desktop = download a client. CLI = install and run in a terminal. Library = you install it into your own project. A project can be several of these.

Two sections

"General" covers everyday development, productivity and fun. "Going global" covers needs specific to running a business outside China: localization, compliance, payments and billing, email deliverability, customer support, auth. Those needs barely exist for domestic products, so they get their own group.

Where the data comes from

Stars, license, language and last-updated dates all come from the GitHub API, refreshed weekly by GitHub Actions. The Chinese descriptions and usage tags are maintained by hand.

Found a mistake?

Broken links, stale descriptions, wrong categories — issues and pull requests are both welcome. The data source is a single JSON file in the repository, so contributing is straightforward.
