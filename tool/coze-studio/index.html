Deploy command

cd coze-studio
   # start service
   # for macOS or Linux
   make web  
   # for windows
   cp ./docker/.env.example ./docker/.env
   docker compose -f ./docker/docker-compose.yml up

Taken from the project README. You need a server with Docker; you may still need to add environment variables.
