在线工具

浏览器里直接可用的小工具，数据不上传服务器

🧩JSON 格式化格式化、压缩、校验 JSON，支持语法错误定位。数据不上传。 🔐Base64 编解码文本与 Base64 互转，正确处理中文和 Emoji。 🔑哈希计算计算 SHA-1 / SHA-256 / SHA-384 / SHA-512 哈希值。 ⏱️时间戳转换Unix 时间戳与日期互转，显示当前时间戳。 🖼️图片压缩在浏览器里压缩图片，可调质量和尺寸，文件不离开设备。 🎨颜色格式转换HEX / RGB / HSL 互转，并生成深浅色阶。 🔤命名风格转换在 camelCase / snake_case / kebab-case 等命名风格间互转。 🔒随机密码生成用系统级随机源生成强密码，可批量。 🔗URL 编解码URL 编码与解码，区分整条 URL 和参数值。 📋文本对比逐行对比两段文本，标出新增、删除和修改。 📝Markdown 预览左边写 Markdown，右边实时渲染。支持表格、代码块、任务列表。 🎯正则测试实时测试正则表达式，高亮匹配并列出捕获组。 🔢字数统计统计字符、中文、英文单词、行数，并估算阅读时间。 🧹文本批处理去重、排序、去空行、去首尾空格、随机打乱。 🎫JWT 解析解析 JWT 的头部和载荷，显示过期时间。 🔟进制转换二进制、八进制、十进制、十六进制互转。 🔣转义工具HTML、Unicode、JSON 字符串的转义与反转义。 📊CSV ↔ JSONCSV 与 JSON 互转，支持带引号字段和换行。 🔄图片格式转换在浏览器里转 WebP / JPEG / PNG，可同时缩放。 ⏰Cron 表达式解析把 cron 表达式翻译成人话，并列出接下来几次执行时间。

🔒 全部在浏览器本地运行，文件和内容不会上传到任何服务器。
