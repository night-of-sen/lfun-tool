在线工具

浏览器里直接可用的小工具，数据不上传服务器

🧩JSON 格式化格式化、压缩、校验 JSON，支持语法错误定位。数据不上传。 🔐Base64 编解码文本与 Base64 互转，正确处理中文和 Emoji。 🔑哈希计算计算 SHA-1 / SHA-256 / SHA-384 / SHA-512 哈希值。 ⏱️时间戳转换Unix 时间戳与日期互转，显示当前时间戳。 🖼️图片压缩在浏览器里压缩图片，可调质量和尺寸，文件不离开设备。 🎨颜色格式转换HEX / RGB / HSL 互转，并生成深浅色阶。 🔤命名风格转换在 camelCase / snake_case / kebab-case 等命名风格间互转。 🔒随机密码生成用系统级随机源生成强密码，可批量。 🔗URL 编解码URL 编码与解码，区分整条 URL 和参数值。 📋文本对比逐行对比两段文本，标出新增、删除和修改。

🔒 全部在浏览器本地运行，文件和内容不会上传到任何服务器。
