📊 CSV ↔ JSON

CSV 与 JSON 互转，支持带引号字段和换行。

🔒 全部在浏览器本地运行，文件和内容不会上传到任何服务器。

关于这个工具

支持双引号包裹的字段（字段里可以有逗号和换行），这是手写解析最容易漏的地方。导出 Excel 用的 CSV 常带 BOM，这里也会自动去掉。
