🔣 Escape Tools

Escape and unescape HTML entities, Unicode sequences and JSON strings.

🔒 Everything runs locally in your browser. Files and content are never uploaded.

About this tool

把用户输入插进 HTML 之前必须转义，否则就是 XSS 漏洞。这个工具也常用来处理被双重转义的数据——先反转义一层看看原始内容是什么。
