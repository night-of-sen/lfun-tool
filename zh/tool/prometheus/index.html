项目简介（摘自 README）

Prometheus 是 Cloud Native Computing Foundation 的一个项目，是一个系统和服务监控系统。它按给定间隔从配置的目标收集指标，评估规则表达式，显示结果，并可在观察到指定条件时触发告警。
