CrawlSEO

一条命令部署 需要一台自己的服务器，但 README 里有可直接执行的 Docker 命令，复制粘贴就能跑起来。

SEO 监控面板：Search Console + 站点爬虫 + Core Web Vitals

SEO监控Core Web Vitals

部署命令

git clone https://github.com/crawlseo/crawlseo.git
cd crawlseo
cp .env.example .env.local
# Add your Google OAuth credentials to .env.local
docker compose up -d db
npm install
npx prisma migrate dev --name init
npm run dev

摘自项目 README。需要一台装了 Docker 的服务器，命令可能还需补充环境变量。
