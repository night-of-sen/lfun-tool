项目简介（摘自 README）

Frontend Slides 帮助没有设计背景的人在不了解 CSS 或 JavaScript 的情况下，制作出精美的网页演示文稿。它采用“展示而非说明”的方式：它不要求你用文字描述自己的审美偏好，而是先生成可视化预览，再让你从中挑选喜欢的效果。
